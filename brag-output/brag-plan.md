# Brag Plan: CroVim

## What is this app?
CroVim is a Vim-style keyboard navigation extension for Chrome that makes everyday browsing fast and keyboard-first without replacing normal browser controls.

## The angle
Treat browser navigation like a calm, precise command-line instrument. The joke is not that Chrome is broken; it is that CroVim quietly gives the web a keyboard layer it should have had all along.

## Hook (first 2-3 seconds)
On a dark teal field, a cursor-like signal blinks beside: “THE WEB HAS A KEYBOARD.” The second line lands: “FINALLY, SO DOES YOUR BROWSER.”

## Key moments (the middle)
- The real CroVim popup language: “Move with intent. Your browser, tuned for flow.” and “CroVim is active on this tab”.
- A working Vomnibar recreation showing the actual search promise: “Search tabs, history, bookmarks, or the web”, with tab/history/bookmark/search results arriving in sequence.
- A compact command burst using real shortcuts: `j k`, `f`, `/`, `o`, `?`, plus the options language “Shape the keyboard-first way you move through the web.”

## Outro / punchline
The command keys resolve into a quiet CroVim wordmark and the grounded line: “Vim-style keyboard navigation for Chrome.”

## User flow worth showing
Open a normal web page → invoke the Vomnibar and type a query → navigate results with the keyboard. The popup and options panels frame the working flow.

## Tone
- Preset: polished
- Creative direction: a quiet command-line instrument for the browser
- Interpretation: restrained, premium pacing with crisp UI reveals, generous whitespace, and one confident music payoff rather than hype.

## Format: landscape — 1920x1080
## Duration: 20 seconds

## Visual identity (from the project)
- Background: `#f4f7f4` / deep ink `#17242a`
- Accent: `#087f73`
- Text: `#17242a` and white on dark panels
- Display font: Inter / system sans fallback
- Body font: Inter / system sans fallback
- Strongest visual element: the teal-accented CroVim popup and Vomnibar cards.

## Share copy (draft)
I made CroVim: Vim-style keyboard navigation for Chrome. Move with intent, search tabs/history/bookmarks, and keep your hands on the keys.

## Audio direction
- Role: warm, polished support with sparse interface accents
- Music: `happy-beats-business-moves-vol-1-by-ende-dot-app.mp3`
- Music treatment: low bed from frame 0, gentle fade-in, slightly more present at the final wordmark, fade out at 20s.
- Music cue guidance: bundled preset read; 120.19 BPM. Strong cues at 17.02s and 20.02s. Use beat-grid windows around 8.02–10.02s for the sequential result rows.
- Audio-reactive treatment: subtle; let the dark hero glow breathe with music energy, never use waveform graphics.
- SFX posture: sparse and precise; clicks for the simulated query and a single soft bell for the outro.
- Audio-coupled moments: search typing, result rows arriving one by one, final wordmark landing.
- Restraint rule: sound should make the interface feel tactile, never louder than the product.

## Storyboard

Sequential/interaction: popup rises, status card settles, actions follow. Audio intent: product reveal. Audio-coupled idea: one soft UI click. Transition mood: soft → Scene 3

### Scene 3 — Vomnibar flow — 5s
Show the actual Vomnibar shell with its search placeholder, keyboard hint row, and four result types. The query appears, then Tab / History / Bookmark / Search rows enter one by one on beat-grid timing and remain readable. Sequential/interaction: yes — type into the search field and reveal result rows in order. Audio intent: tactile and useful. Audio-coupled idea: key/click accents on query and first/last result. Transition mood: clean → Scene 4

### Scene 4 — Keyboard command burst — 4s
Large keycaps for `j k`, `f`, `/`, `o`, `?` appear as a compact command vocabulary, paired with “scroll”, “link hints”, “find”, “Vomnibar”, “help”. Sequential/interaction: yes — keycaps arrive left to right, labels follow. Audio intent: measured rhythm. Audio-coupled idea: sparse clicks. Transition mood: dramatic → Scene 5

### Scene 5 — CroVim — 4s
Dark ink panel with the CroVim mark and “Vim-style keyboard navigation for Chrome.” A final small line: “Move with intent.” Beat-locked to the 20.02s cue. Sequential/interaction: none. Audio intent: confident finish. Audio-coupled idea: one soft bell on the wordmark. Music: warm and present, then fade. Transition mood: soft → end
